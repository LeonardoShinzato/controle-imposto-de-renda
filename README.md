Organizador e centralizador os dados para a Declaração de Imposto de Renda
# Controle de Declaração de IR

Planilha em Excel para organizar todas as informações necessárias para a Declaração de Imposto de Renda como dados pessoais, rendimentos bancários e movimentações financeiras do ano.

## Sobre o projeto

Este projeto foi feito para resolver um problema comum relacionado a quantidade de informes que uma pessoa adquiri durante o ano, compilando em um único arquivo onde tudo fica organizado e pronto para consulta na hora de declarar.

## Funcionalidades

- **Dados do titular**: nome, CPF, nascimento, título de eleitor, endereço, contato e informações sobre dependentes/cônjuge, tudo em um só lugar.
- **Informes de rendimentos bancários**: registro dos valores atuais em cada banco, com campo para anexar o PDF do informe de rendimentos correspondente.
- **Controle de entradas**: registro de entradas financeiras por data e categoria (ex: CNPJ, salário), útil para conferência e holerites.

## Estrutura da planilha

| Aba | Conteúdo |
|---|---|
| `TITULAR` | Dados pessoais do declarante |
| `INFORME` | Rendimentos bancários por instituição|
| `NOTAS` | Controle de entradas financeiras por data e categoria |

## Como usar

1. Baixe o arquivo `.xlsx` deste repositório.
2. Abra no Microsoft Excel.
3. Preencha os campos de cada aba com os seus dados.
4. Para cada banco, anexe o informe de rendimentos correspondente.

## Requisitos

- Microsoft Excel 365 ou versão compatível.
